# JUZARA Health — Visual Design System v0.4

## Creative direction
Illustrated healthcare app inspired by the supplied reference: playful tiger-doctor mascot, clinic and nature landscapes, rounded phone-like surfaces, soft clouds, warm cream cards, turquoise skies and orange actions. The visual language must remain friendly without reducing clinical clarity.

## Palette
- Sky turquoise: `#55CFC5`
- Deep teal: `#278E86`
- Action orange: `#F47721`
- Peach: `#FFCFaa`
- Warm cream: `#FFF7E9`
- Cocoa text: `#452719`

## Components
- Rounded cards and pill-shaped actions
- Soft, low-contrast shadows
- Illustrated landscape hero areas
- Friendly mascot accents
- Patient, doctor and admin portals share the same visual language
- Distinct role navigation and role-specific content

## UX rules
- Use the same illustration style across patient and doctor experiences.
- Keep forms, clinical values, queue numbers and lab results highly legible.
- Never use invented patient or laboratory values as real records.
- Display a demo label on seeded/example facility and schedule information.
- Doctor access is granted only by an administrator after credential verification; the backend remains authoritative for authorization.
